# 威胁模型

这份文档是为确定“防护应该放在哪一步”，真正造成损失的路径只有少数几条。

## 老人为什么容易中招

不是判断力问题。这些骗局是按固定的心理机制设计的：

|利用的心理|常见说法|
|-|-|
|时间压力|两小时内不处理将冻结账户|
|权威|冒充公安、法院、社保局、银行客服|
|损失厌恶|医保卡异常、包裹被扣需缴保证金|
|熟人信任|盗号后向通讯录群发、冒充子女借钱|
|怕麻烦子女|这点小事不用问了，我自己弄|
|分不清网页与 App|把"登录"当成"授权"，把"安装"当成"打开"|

指望靠反复叮嘱解决不现实。有效的做法是让危险的那一步在系统层面做不到。

## 五条主要路径

### 一、短链跳转到仿冒页面，由本人填写信息

```
短信或微信里的短链
   ↓
仿冒页面（ETC 失效、社保停发、快递异常，要求"验证"）
   ↓
填写身份证、卡号、密码
   ↓
填写"银行发来的六位数字"（实为转账验证码）
```

这条路径里手机没有任何异常，杀毒软件也查不出问题，操作是受害者自己完成的。能拦住的是链接判定与域名拦截；拦不住的是"页面看起来很正常"这一点。

### 二、冒充客服，诱导安装远程协助或开启屏幕共享

```
冒充银行客服或公安，称账户涉案
   ↓
要求下载"安全防护"类应用，或使用会议软件共享屏幕
   ↓
在屏幕共享状态下输入密码、口述验证码
```

受害者是主动配合的，用的是正规软件的合法功能。技术上难以拦截，唯一有效的防线是家规与安装来源限制。

### 三、木马安装包

```
链接直接指向 .apk（"银行内部版""补贴申领"）
   ↓
安装后申请读取短信、无障碍、设备管理权限
   ↓
读取银行验证码、模拟点击转账、锁屏勒索
```

从应用商店之外安装的程序，系统不会审查。一旦授予读取短信和无障碍权限，手机基本等于交给了对方。这一层能挡在三处：安装包直链的域名、未知来源安装开关、权限检查。

### 四、摇一摇广告误触

应用开屏广告在设备轻微晃动时跳转，落到电商应用或浏览器落地页，再引导下载。这条路径直接造成的损失有限，但它是"意外打开陌生页面"的主要来源，老人往往说不清自己是怎么到那儿的。

### 五、诱导开启无障碍权限

"为了帮您操作，请开启无障碍服务"。开启后该应用可以读取屏幕内容、模拟点击、自动填写表单、自动确认转账。这是 Android 上权限最高的开关之一，正常应用几乎不需要它。

## 防护应该下在哪一步

|路径|主要防线|
|-|-|
|一、仿冒页面|域名白名单与高风险域名判定，拦截发生在建立连接之前|
|二、远程协助|家规、未知来源安装限制|
|三、木马安装包|关闭未知来源安装、安装包直链拦截、权限检查|
|四、广告误触|DNS 层拦截落地页域名|
|五、无障碍权限|定期检查权限列表|

顺序上，系统加固优先于软件拦截。它堵的是"装进去"和"给权限"这两步，一旦发生很难回退；而链接拦截只能降低点开陌生域名的概率。

## 为什么工具选择本地运行、离线判定

不把链接上传到任何服务，判定的依据是本地规则库；DNS 过滤本身运行在本地设备或家庭网络内。代价是缺少云端情报的实时性，名单需要人工定期更新，对中文诈骗站的覆盖也有限。

## 附：手机加固清单

软件拦截只能降低"点开陌生域名"的概率。下面这些设置堵的是"装进去"和"给权限"这两步，一旦发生很难回退，优先级更高。

不同品牌与系统版本的菜单名称不一致，**找不到菜单项时直接在设置顶部的搜索框里搜关键词**，比逐层找可靠。

### Android

|项|做法|挡住什么|
|-|-|-|
|关闭安装未知应用|设置搜索「安装未知应用」，把浏览器、微信、文件管理、下载工具全部设为不允许|木马安装包|
|清理无障碍服务|设置搜索「无障碍」，除系统读屏外全部关闭；不认识的条目卸载对应应用|读屏窃密、模拟点击转账|
|检查设备管理器|设置搜索「设备管理」，除系统组件外取消勾选并卸载|锁屏、清空数据、改密码|
|打开纯净模式|华为、荣耀搜索「纯净模式」；其它品牌搜索「支付保护」「安全」|非官方渠道安装|
|打开链接前询问|设置搜索「打开链接」「应用跳转」，选每次询问或禁止跳转|广告误触与随意跳转|
|关闭小额免密|微信：支付设置 → 免密支付；支付宝：支付设置 → 免密支付与自动扣款|小额连续扣款|
|锁屏通知不显示内容|设置 → 通知 → 锁屏通知|验证码显示在锁屏上|

### iPhone

iOS 不允许第三方应用做全局网络过滤，能做的只有以下几项：

* 设置 → Safari 浏览器 → 打开「欺骗性网站警告」。该功能只在 Safari 生效，微信内置浏览器不受影响
* 设置 → 屏幕使用时间 → 内容和隐私访问限制 → 安装应用改为不允许，修改需要密码
* 设置 → 通用 → VPN 与设备管理：出现不认识的描述文件立即删除。安装描述文件等于允许对方下发根证书与网络配置
* 设置 → 隐私与安全性 → 关闭「App 请求跟踪」
* 改 WiFi 的 DNS 有效，蜂窝网络的 DNS 改不了

### 微信

* 关闭自动下载：设置 → 通用 → 照片、视频、文件和通话
* 精简发现页：设置 → 通用 → 发现页管理，用不到的入口全部关闭
* 内置浏览器不受 Safari 的内容拦截影响，只有网络层的 DNS 过滤对它同样生效

### 银行与支付

* 设置单笔与单日转账限额，调到日常够用即可
* 转账选择延时到账，例如 24 小时到账，留出撤回时间
* 开通动账提醒，子女手机上也安装同一家银行的应用并开通

### 家规

写在纸上贴在冰箱上：

> 不管谁让你做下面任何一件事，先挂电话，打给我：
>
> 安装应用、开启屏幕共享或远程协助、报验证码、把钱转到"安全账户"、点短信里的链接去处理账户问题。

另外两句同样重要：

* 声音可以合成，视频可以换脸。"是我"三个字不代表真的是
* 让你别告诉家里人的，一定有问题。真警察不会要求你对家人隐瞒

### 每月复查

* 安装未知应用是否被重新打开
* 无障碍列表是否有新增条目
* 设备管理器是否有陌生应用
* 手机里是否出现名字类似"安全""清理""加速""助手"的陌生应用
* 银行与支付账户有无异常动账

### 已经中招

1. 打银行客服挂失卡片
2. 拨 96110 报警
3. 先开飞行模式，不要卸载可疑应用，它是证据，之后带去派出所
4. 用另一台干净的设备修改所有相关密码
5. 查询征信，确认是否被开通网贷

96110 是全国反诈专线，也可以主动拨打核实可疑来电。国家反诈中心应用提供来电与短信预警，与本文所述工具不冲突。

技术手段的作用到此为止。真正防住大多数情况的，是上面这些设置，还有那张贴在冰箱上的纸。
