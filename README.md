# 护链 LinkGuard

适配Android 15及以上系统，在 DNS 层执行域名白名单，名单外的网站因无法解析而打不开。

面向家里老人的手机，由子女安装并设置一次密码，之后老人不需要做任何配置。

<sub>English: An Android 15+ app that enforces a domain allowlist at the DNS layer via `VpnService`. Domains outside the list fail to resolve. Built for elderly users, whose set of legitimate sites is small and stable. Offline; no data leaves the device.</sub>

## 为什么用白名单

老人日常访问的合法网站其实不多。微信、支付、银行、购票、地图、天气、快递，加上几个常去的店铺，通常不超过二三十个，且长期不变。这个集合能够列举完整。

黑名单相反，它要求把所有坏域名都列出来。域名天天在新增，公开情报对中文诈骗站覆盖有限，漏掉一个，诈骗站就能正常打开，而且通常要等出事才知道。白名单漏掉一个，表现为某个正常网站打不开，当场就能发现并补上。

对于这个业务场景而言，白名单比黑名单更有用：**可穷举、出错可见、对未知链接默认拒绝。**

## 工作方式

```
应用要访问某网站
      |
  系统发出 DNS 查询
      |
  护链接管（只接管 DNS）
      |
  +---+---+
  |       |
 名单内   名单外
  |       |
转发上游  本地回 NXDOMAIN
正常访问  拿不到 IP，连接未建立
```

拦截发生在建立连接之前，对方服务器收不到任何请求。只接管 DNS，其它流量不走隧道，网速和耗电基本不受影响。

## 三种模式

|模式|行为|
|-|-|
|严格模式（默认）|只放行白名单内的网站|
|智能模式|默认放行，只拦高风险域名特征|
|排查模式|不拦截，只记录|

严格模式是推荐配置，切换模式需要密码。

智能模式按五类域名特征判断：`xn--` 同形字、批量注册的廉价后缀、含品牌词但不在官方域下、多个诱导性词拼接、连字符过多。

## 正常软件/网址打不开？使用学习模式

高级设置里有「学习」入口：关闭其他软件，点一下“临时放开限制”，打开目标软件使用一段时间，回到护链时会列出需要的域名，确认后一次写入白名单。只需要选"加入"或"丢弃"。

也可以手动加：网站管理页支持搜索、从被拦记录添加、粘贴完整链接自动提取域名。

## 主要功能

* 146 条内置白名单，覆盖小米、华为、荣耀、OPPO、vivo 的系统联网与推送域名，以及银行、支付、政务、地图、出行、电商
* 白名单与被拦记录支持搜索和折叠，可单独移除、可一键重置
* 学习功能：一次操作把某个软件所需的域名收入白名单
* 切换模式、进入网站管理需要密码，连错后逐次延长冷却
* 通知栏常驻（前台服务），被清除后 15 秒内自动恢复
* 一键诊断：直接测 DNS 链路并给出内部计数
* 广告与追踪域名拦截（25 条，仅严格模式）
* 完全离线，无账号、无遥测

## 安装

1. 从 Releases 下载 APK，安装时允许一次「未知应用」，装完立刻关掉
2. 设置管理密码 → 开启保护 → 允许 VPN 连接
3. 做一次保活设置，否则国产 ROM 会清理掉服务

|品牌|设置|
|-|-|
|小米 / Redmi|省电策略无限制、允许自启动、最近任务加锁|
|华为 / 荣耀|应用启动管理改为手动、关闭电池优化|
|OPPO / 一加 / realme|允许后台运行与自启动|
|vivo / iQOO|允许后台高耗电与自启动|

详见 [android/README.md](android/README.md)。

## 能力边界

能拦住"域名本身可疑"的一类：陌生短链、仿冒银行或政务的域名、指向安装包的直链、广告落地页、已收录的恶意域名。

拦不住的：

|情况|原因|
|-|-|
|域名正常、内容是骗局|不读取页面内容|
|正规站被入侵后挂的马|域名在白名单里|
|云存储桶里的钓鱼页|共享 CDN 为图片视频放行|
|同一域名下的钓鱼路径|HTTPS 加密，看不到路径|
|已缓存的 IP、已建立的长连接|只拦解析这一步|
|应用自带 DoH / HTTPDNS|协议层绕过|
|已装的木马、无障碍权限、屏幕共享|不属于 DNS 范围|

**它降低"点了陌生链接就中招"的概率，挡不住"自己把卡号填出去"和"手机已被人控制"。** 后者要靠系统加固：关闭安装未知应用、清理无障碍服务、检查设备管理器，以及与家里人事先说好的一条规矩。

## 验证状态

单元测试 75 个全部通过，覆盖 DNS 报文、校验和、域名匹配、判定引擎、应答裁剪、学习结果整理。

真机验证在小米 Android 15 上完成。过程中修掉过一个致命缺陷：应答包目的地址误用请求包的 `dstIp`（指向自己）而非 `srcIp`，导致内部统计全部正常但设备上任何域名都解析失败。现有三条回归测试守着这个行为。

未验证：其它品牌与系统版本。当前 `minSdk = 35`，只能装在 Android 15 及以上。
